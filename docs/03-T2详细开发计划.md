  1. `ts ≥ front`（顺序）→ 正常 `ingest`，`front = ts`；
  2. `front − skew_window_min ≤ ts < front`（迟到但窗内）→ **`replay_car` 重算**：按车查事件日志 `WHERE "BODY_ID" = :b AND "DATE_EVT" BETWEEN :since AND :now ORDER BY "DATE_EVT","ID"`（在池车 `since = entry_ts` 全周期重算；不在池车 `since = now − 24h` 上限），再按合并规则并入：
     - **合并规则**：`station / flag / loop_count / last_event_ts` = 重算结果（同一套 R1/R2/R6 状态机重放）；**`entry_ts / exits_seen` 不动**（生命周期计数只来自顺序事件）；不在池车 → 重算结果最新事件在非出站、非出站延续站（且过动态历史锁）才按 R4 收养（`entry_ts` = 日志首事件 ts，标注「近似」），最新事件在出站站或出站延续站 → **不收养仅审计**（在池车池移除，与 R4 双保险一致，2026-09-24 修订）；**站级 ts 并入**：重算切片涉及的各站，其最近过车 ts 取 现值 与 切片内该站事件 ts 的 max（max 语义幂等，与 ingest 单点更新一致，2026-09-24 代码审核补）；
     - **幂等**：同一事件日志 + 同一池状态 → 同一结果；同一迟到事件重算两次 → 状态不变且审计计数不重复（row_id 去重：池内维护每车近期 row_id 小集合）；
  3. `ts < front − skew_window_min`（更旧于窗）→ `audit["late_out_of_window"] += 1`，不动池状态（每日全量核对兜底）。
