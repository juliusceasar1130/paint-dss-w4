## 1. PG 237 映射模型（2026-10-09 全量裁决定稿，v2）

```text
PG 1..30   = 30 字符 MES 通信头（官方定义未覆盖）
PG 31..154 = 官方 Byte 0..123（124 字节逐字符对应，1-based 偏移 +31）
PG 155..172 = 官方 Byte 124..135（3 个 DINT 共 12 字节，ASCII 序列化展开为 18 字符）
PG 173..237 = 官方 Byte 136..199（64 字节 → **65 字符**：`SkidDestination` 4 字节 DINT 序列化为**5 位十进制文本**（PLC 显示可达 5 位，2026-10-09 用户确认），其余后半段 DINT 均 4 位，净 +1 字符，1-based 偏移 +37）
无独立尾字段：PG 237 = `Reserve2` 第 18 字符（值域 {0: 492.7万, -: 198.8万, 4: 14.6万, _: 3.3万}）
30 + 124 + 18 + 65 = 237
```

**v2 修正记录**：v1 模型（审计报告初稿 / 本文档初稿）按 `SkidDest` 4 位（209..212）+ 独立尾字符 237 处理，后半段整体左移 1 位。agy 二审提出后，2026-10-09 全量（7,093,971 行）裁决推翻，agy 独立复验 14/14 同意：
- 213 位值域含 3/6/7/8/9（22,916 行）→ 213 是 SkidDest 第 5 位数字，非独立标志位；
- 209..212 与 213 零混合 dash/数字模式 → 5 位 DINT 文本序列化；
- `FULLSKID` 起于 220（910,992 行）、起于 219 = 0 行 → `Reserve2` 起于 220；
- 样本 `17001`（756,772 行）/ `00380`（156,797 行）真实存在（含前导零、超 9999）；
- 算术闭合 30+124+18+65=237，64 字节→65 字符唯一差异 = SkidDest 5 位序列化。
证据与 agy 交叉验证记录：`output/mds_audit_report_recheck_20261009.md` §10。
> ⚠ `output/skiddest_feasibility_evaluation_report_20261009.md` 使用 209..212 4 位切片，其工位码统计（153..228 码、单车 22.1 次变更等）为 5 位值前 4 位截断，复用前需按 209..213 重测。

## 4. 特殊群体与关键实测事实（全量 7,093,971 行，2026-10-09）

- **15,652 空车 TE 行**：`MDS_TELEGRAM_TYPE=TE`、`BODY_ID` 全 dash、173..186=`--------------`、PartFlags=`--`、NoPaint/SecondRun=`-`，skidId/DATE_EVT 正常——「空车 TE 过站报」。
- **1,015,128 空车占位行**（BODY_ID 全 dash，≈14.3%）：skidId 与 `SKID_ID` 列 100% 一致、173..186 多为有效时间戳——占位报也是真实滑撬过站电报，可用于滑撬轨迹分析。
- **双色车**（APT1<>APT2）：495,502 行（6.98%），`APT2='A1PQ0---'` 仅 1 反例。
- **CodeF(137)=1 ≈ 黑顶/双色标志**：与颜色代码 `A1` 后缀 100% 互证（58 万行零反例）；「非 A1 色但 137=1」123 例 = 4 辆返修补喷黑顶车。
- **TCLineBlockRoof(194)=2**：110,603 行、100% 黑顶/双色（0 反例）；值 1 = 12,506 行、值 3 = 1,987 行（含义待确认）。
- **KVS Flag(140)=1**：172,154 行（约 75% 黑顶 / 25% 单色），**与双色车顶不等价**（双色车 49.6 万行中仅 12.9 万 KVS=1）——「KVS=1 为双色车设置」断言被数据否定。
- **CodeA(138)=2**：13 行 = 单一车 `78202681900889`（2026-05-11，连续过站，137=1 黑顶）。
- **CodeB(139)=3**：4 行，集中 2026-04-17 08:14~08:42（历史异常报文）。
- **139=2 触发高度集中**：`14IS260`（47%）+ `24IS185`（26%）= 73%，前 9 个读写站 = 98.4%（2026-09 实测）。
- **电报类型分布**：TS 6,101,099 / TC 789,769 / TE 108,362 / TB 93,237 / TO 832 / TI 672，与 `MDS_TELEGRAM_TYPE` 列逐类 100% 一致。
- **SkidDest(209..213) top 值**：`00000` 267.3万 / `17001` 75.7万 / `25385` 21.1万 / `29030` 19.7万 / `10440` 18.3万 / `00380` 15.7万。
- **Reserve2(220..237) 模式**：`-----------------0` 491.2万 / `FULLSKID----------` 89.6万 / `------------------` 80.0万 / `EMPTYSKID---------` 29.1万 / `-----------------4` 14.5万 / `__________________` 3.3万；`FULLSKID` 共 910,992 行、`EMPTYSKID` 共 291,358 行；异常模式 `-------,---------0` 1,335 行（含逗号）。
- **单一孤例**：`ID=114319203`（2026-05-14 16:35:57，站 01IS222，TB）列值与 MDS 载荷不同源（BODY_ID 与 MDS 31..44、SKID_ID 与 197..200 各不一致）；列值互证率 99.999986%。

## 5. 2026-09 全量实测结论（继承自原 docs/08 §2.2，662 万行口径）

1. **定长 237 无例外**（6 类电报 min=max=237）→ 按位置硬编码截取安全；若 MES 改版，长度偏离 237 是第一个预警信号。
2. **位序正确性三重验证**（2026-09 口径）：
   - 31-44 位与独立列 `BODY_ID` 比对 6,623,848/6,623,849 一致（唯一孤例 `78114319203…` ID=114319203，见 §4 孤例）；
   - 45-49 位与 `BODY_TYPE` 左 5 位 100% 一致；
   - 137/139 位与滚床报文 26/27 位跨链路比对全部通过。
3. **137-140 完整值域穷举**（2026-09 口径；官方名见 §1，俗称已废弃）：

| 位 | 完整值域 | 关键说明 |
|---|---|---|
| 137 (CodeF) | {0, 1, -} | 黑顶标志；与颜色代码 `A1` 后缀 100% 互证（58 万黑顶车零反例） |
| 138 (CodeA) | {0, 1, **2**, -} | 实测**跟随 137**；值 2 仅 13 条（1 辆车）——疑非纯预留 |
| 139 (CodeB) | {0, 1, 2, **3**, -} | 0=正常 / 1=返工 / 2=黑顶二次喷涂（2026-09-19 用户拍板）；**3 仅 4 条**（2026-04-17 凌晨异常报文） |
| 140 (KVS Flag) | {0, **1**, -} | 值 1 有 169,760 条（2026-09 口径；2026-10 全量 172,154），**与黑顶车强相关**——官方语义未明（§7 #8） |

4. **语义推断（重点结论）**：
   - **137/138 基本终身不变**：137 位真实变化仅 4 辆车、138 位仅 6 辆（其余「变化」为空占位符重置或调试号 `99999999999999` 造成）；发生变化的车辆全部与「返修补喷黑顶」相关；
   - **138 不是 137 的简单影子**：有 2 辆车「137 不动、138 单独变化」；
   - **140=1 疑似与黑顶流程相关**（黑顶车 1101/1121 组合为主）——待官方定义确认（§7 #8）。
5. **注意 MDS 四位排列顺序与滚床不同**：MDS 为「黑顶 137 → CodeA 138 → 返工 139 → KVS 140」（预留夹中间），滚床为「黑顶 26 → 返工 27 → 预留1 28 → 预留2 29」。
