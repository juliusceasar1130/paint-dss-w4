# 返工净延误重构（Net Delay Optimization）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 彻底解决 W1/W2 因 MES 标志位不复位导致的 $L_1$（40h）虚高、末端工位虚假累加穿帮、以及高返修车型（YM33J-）双向错配问题，在 W2 学习器中产出无偏双列的 `dss.dim_expected_delay`，重构 `eta_v2.py` 推理引擎，并在 W2/W3 回放中复验达标。

**Architecture:** 
采用“纯只读预演 $\rightarrow$ 止血固化 $\rightarrow$ 维表生产 $\rightarrow$ 引擎切换 $\rightarrow$ 双基线回归”的分步递进架构。W1 保持零代码改动；新维表在 W2 学习器（`spike_w2/01_learn_v2.py`）中基于 ⑥a 净化前环人群全窗概率 $P_{\text{clean}}(\text{fut})$ 和基线修正项学出；W2 推理引擎（`spike_w2/eta_v2.py`）增加 `DSS_USE_NET_DELAY` 环境变量无损回滚保护；W3 消费新引擎，自动继承收益。

**Tech Stack:** Python 3.10+, PostgreSQL (analytics_db @ 127.0.0.1:5432, schema: `dss`), psycopg2, pandas, pytest, python-dotenv.

- **操作系统与环境**：Windows PowerShell，专用环境 `paint-dss`（必须使用 `conda run --no-capture-output -n paint-dss python <脚本>` 执行）。

- **配置与回滚规范**：所有控制参数使用 `DSS_*` 环境变量；支持 `DSS_USE_NET_DELAY=1` 开启新引擎，`DSS_USE_NET_DELAY=0` 30 秒无损回滚。

## Task 2: W2 学习器落地新表生成与三级退化 (`01_learn_v2.py`)

**Files:**
- Modify: `spike_w2/01_learn_v2.py:30-65` (DDL)
- Modify: `spike_w2/01_learn_v2.py:240-330` (新增新表学习逻辑)

**Interfaces:**
- Consumes: 学习窗全量事件 `tmp_ev_base`、`dss.v2_future_flag`
- Produces: `dss.dim_expected_delay (body_type, station, delay_mean_s, delay_p50_s, sample_n)`

- [ ] **Step 1: 在 DDL 中添加 `dss.dim_expected_delay` 表结构**
  ```sql
  DROP TABLE IF EXISTS dss.dim_expected_delay;
  CREATE TABLE dss.dim_expected_delay (
      body_type TEXT NOT NULL,
      station TEXT NOT NULL,
      delay_mean_s BIGINT NOT NULL,
      delay_p50_s BIGINT NOT NULL,
      sample_n INT NOT NULL,
      sample_n_clean INT NOT NULL,
      PRIMARY KEY (body_type, station)
  );
  ```
- [ ] **Step 2: 编写产出新表的 SQL 与三级退化聚合逻辑**
  1. 计算 `base_clean` 的 P50 与 Mean；
  2. 计算 `fut=1` 车身的净增量 $\mathbb{E}[T_{\text{rem}} - T_{\text{clean}}]$；
  3. 计算 `delay_mean_s = max(0, round(P_fut * diff_mean + (mean_clean - p50_clean)))`；
  4. 计算 `delay_p50_s = max(0, round(P_fut * diff_p50))`；
  5. 落地三级退化：
     - Level 1: `(body_type, station)` (若 $N \ge 30$)
     - Level 2: `(body_class, station)` (若 $N \ge 30$)
     - Level 3: `('ALL', station)` (若 $N \ge 30$) $\rightarrow 0$ 兜底。
- [ ] **Step 3: 在 `01_learn_v2.py` 的 sanity check 中加入新表校验**
  校验项 S5：
  - 检查 `dss.dim_expected_delay` 总行数 $> 500$；
  - 检查无负数延误（`min(delay_mean_s) >= 0` 且 `min(delay_p50_s) >= 0`）；
  - 检查核心站（22IS340, 22IS005）的 delay 值非空且在物理合理区间。
- [ ] **Step 4: 执行学习器构建**
