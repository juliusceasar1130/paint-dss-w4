## W1 — 节拍学习器 + 单车回放（当前阶段）

**目标**：验证最高风险假设「位置×节拍能否预测准」。

**范围**（`spike_w1/`）：
- `01_learn_takt.py` → `dss` schema 五张学习表：
  1. `dim_remaining_time` 主分布（车型×站，**干净后缀**：每车最后环事件后的 flag=0 事件）
  2. `dim_loop_remaining` 环分布（车型×标志{1,2}×站）
  3. `dim_station_takt` 段级诊断（LAG 差分 + Q3+3×IQR 桶内清洗 + 夜停剔除）
  4. `dim_future_flag` 未来标志概率 p（车型×站 → p1/p2）
  5. `dim_loop_duration` 环时长 L（车型×标志 → 中位数）
  + `dim_learner_meta`（窗口/样本量/剔除率等元数据）
- `02_replay_eta.py` 三估计器对打（因果切分：前窗学习 → 后窗回放）：
  - Σ段中位数（预期失败——中位数不可加，作诊断）
  - Σ段均值（无偏、高方差）
  - **直接剩余分布**（主候选）+ 环分流 + 前决策补偿（`ETA = P50(主) + p×L`）

**验收**：
- 单车 ETA 中位误差 ≤30min（直接剩余分布估计器，量产车、完整行程车）
- 学习表 sanity：入口站 P50 ≈ 全程 16–20h；p 在决策站（15IS065/13IS065/14IS065）呈阶跃、下游 ≈0；环表 n 充足（返工 13,010 台/黑顶 9,711 台）
- 顺带确认：08IS/09IS 分叉前共享站 P50 近无偏（五确假设的回放实证）
- 验证摘要写入 `output/` 并 commit

**失败判据**：中位误差 >30min → 按车型/站分桶定位误差源，未诊断清楚不进 W2。

**不在范围**：班次级聚合（W2）、在线化（W3）、展示层。

## W2 — 班次级回放

**目标**：验证「班次达成能否预测」——±10% 门。

**范围**：
- 班次窗：自学运行窗口（04:45→02:30）+ 归班口径（提早开工 04:45–正式开班下线计日班；中班 16:30 开）
- 逐车 ETA → 按下线时刻归班 → 车型维度汇总
- 回放设计：在班次**第 5 小时**时刻，用当时的在制车状态预测该班最终达成（模拟真实使用场景）

**验收**：班次级第 5 小时预测误差 ≤±10%（车型汇总）；返工车（15.6%）单独修正并成组显示。

## W3 — 在线滚动预测 + 缺口预警

**目标**：生产可用——每 5min 对在制车滚动 ETA，班次缺口预警。

**范围**：
- `dim_shift_target`：周计划表「进、出车计划」段解析（文件夹监听 + 解析器）
- 在线 ETA：车最新事件 → 选分布（flag=0 主 / flag=1,2 环）+ 前决策补偿 + 跨班修正
- 缺口预警：Σ(ETA≤班末) + 本班已下线 vs 班次目标 → 缺口量 + **定位**（缺口车堵在哪段）
- 展示从简：最小形态先跑，预警渠道/看板位置按用户指定

**验收**：连续 5 天稳定运行，班次达成预测 ±10%。

**阻塞**（用户输入）：
- 周计划表**固定文件夹路径**
- 首次完整周计划表（含进、出车计划段）放入该文件夹

## 模块① — WIP 看板 + 水位预警（② 之后）

三层架构：看板（常显）/ 预警（主动推送）/ agent（交互下钻）；看板与 agent 共用同一指标层（单一事实源）。

**范围**：区域×车型矩阵（249 区）、占用率红黄绿、异常车/项目车/滞留车、作息偏差；
阈值预警（>90% 红 / <10% 放空）+ 滞留超时（retention_checkpoint 已就绪）；防抖（迟滞 + 去重 + 告警日志）；预警分级（P1 堵塞才弹送）。

**依赖**：位置历史快照归档（数据积累期）→ 并行任务立即启动。
**阻塞**（用户输入）：249 区 ↔ 259 站映射；预警推送渠道 + 看板摆放位置。

## 模块③ — 流量均衡建议（① 之后，或视杠杆清单到位并行）

透明规则引擎（不用 ML）：纠偏 / 预防 / 配比 三类建议；starving/blocking 特征
（上游满+下游空同现）→ 堵塞定位；瓶颈定位 = 段级 takt 的 P90/P50 倍率排序；
开班检查单（班初水位 vs 建议水位，v1 首批）；反馈回路（建议日志 → 采纳率 → 效果回评）。

**硬原则**：每条建议可解释（带依据数据）；P1 才弹推送；宁缺毋滥（每天 5 条靠谱 > 50 条噪声）。
**演进**：v1 规则 → v2 反馈学习排序 → v3 SimPy 预演 → v4 远期 DRL reward 基础。
**阻塞**（用户输入）：现场干预杠杆清单（入口投放能否控 / 缓存释放能否调 / 返工插入谁定）。

## 并行任务：快照归档（立即启动，半天纯 DB 动作）

`rb_position_data` 每 5min TRUNCATE+INSERT 全量刷新 → 位置历史丢失。
加历史快照归档（增量追加，不动 ETL 主链路）。
**定位**：模块①③的时间杠杆——每晚启动一天，①③ 晚一天上线。
