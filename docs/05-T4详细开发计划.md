### 2.2 关键口径（拍板继承 + F 系列实测，实现必须照此）

1. **全天预测（F3 union + F10 激活窗）**：`pred_day_total(t) = A_day(t) + A_mid(t) + |{v∈池: rem 非空且 t+rem/α ≤ 当日较晚班末}|`；每车只计一次。**仅在中班时段 [16:30, 次日 04:00) 激活**（封闭在制，F10 闭合论证）；日班时段无全天 scope——日班时段主预警 = 日班班次视图（16:30 时界同样封闭：16:30 前出场的车必于 04:30 前已进场）。α 按 `cfg.alpha_mode`（生产默认 off=1.0）。
2. **班次预测（调度班组视图）**：`pred_shift(t) = A_shift(t) + |{v: t+rem/α ≤ shift.end}|`（W2-v3 原式，不依赖拆分）；目标 = `split_target`。
3. **Δ**：`Δ = (pred − target)/target`（target=0 → 该 scope 无告警，记绿）。
4. **瓶颈车（F4）**：`{v: rem 非空且 t+rem/α > scope_end}`（day_total scope_end = 当日较晚班末；shift scope_end = shift.end）；自洽恒等式 `池产品车 = 在制 + 瓶颈 + no-ETA`（精确，断言 + 报告）。
5. **flag 分层（F5）**：rework_n = flag=1（质量返修）；blacktop_n = flag=2（黑顶双色，正常工艺）；主线 = {0,−}；瓶颈直方图按段 × 返修/黑顶/主线 三维。
6. **去抖（物理时差判据，agy 中③）**：双向均需持续 `DSS_ALERT_DEBOUNCE_MIN`（10min）——判据 `(t − pending_since) ≥ timedelta(minutes=cfg.alert_debounce_min)`（aware 时间戳差值；5min 步长下 = 第 0 步检测 / 第 1 步 5min / 第 2 步 10min 确认，共 3 轮采样）；确认前闪回原档 → 清零；首档（初始态）在 scope-day 首次 evaluate 即确认（基线留痕，不等 10min）；debouncer 状态按 scope-day 隔离重置。
7. **STALE 冻结（docs/02）**：guard 非 FRESH → 不出新告警、不确认新档（现有档保持，横幅展示）。
8. **A(t) 取数（F9）**：预取回放窗出口事件时间线，内存 bisect 计数（零逐步 DB 查询）。
9. **缺排班日**（休/停产）：无 scope，不告警（docs/08 安全网）。
10. **scope 空窗与除零保护（agy 低①②）**：04:00（中班末）→ 04:45（次日日班归属起点）空窗无活跃班次 → `evaluate()` 返回空列表、debouncer 冻结；停产日 / target=0 时该 scope 不告警、**不计算 Δ**（防 ZeroDivisionError）。
