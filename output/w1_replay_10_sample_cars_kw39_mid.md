## 四、误差归因（2026-10-07 自查，真库实证）

**A. 假期跨停（3 台：78202664100770 / 78202682685297 / 78202683921714，09-24 上线、09-26 下线，总耗时 40~48h）**
入口误差 −9.2h / −21.9h / −24.2h，均为 ETA 早于实际。逐站核验（`scratch/tmp_kw39_selfcheck.py`）：
- 2N54Y- 车（78202683921714）符号干净：56 站偏早 / 1 站偏晚，末站收敛到 0 —— 与“ETA 系统性提前 ≈ 停线时长”一致；
- YM33J- 车（78202664100770）符号混杂（28 早 / 33 晚，中段 +1445）：该车型 P50 行本身偏长（YM33J- 03IS060 P50=39.6h vs ALL 14.7h），**部分“碰巧”吸收了停线**（入口误差仅 −9.2h 而非 −29h）；
- SS22H- 进环车（78202682685297）主体偏早（52/69 站），环内区段有独立偏置（+324 min）。

结论：静态 P50 无法建模计划外全停，方向与量级与停线时长一致；长滞留车型的偏早幅度被其长 P50 稀释。**逐站符号非全负**：仅 2N54Y- 车全程干净；YM33J- 车 09-26 重启后受其历史长滞留偏置反转（中段 +900~+1445 min），SS22H- 车环内区段独立偏置（+13~+323 min）。

**班次级交叉验证（agy-2 独立查库核验，10-07）**：“09-26 重启日低估 29.15%”（实际 638 vs 预测 452）与单车偏早**同为假期非稳态、但机理方向相反**：09-26 下线的 638 台中 **488 台（76.5%）**是周五停线前上线、车间内积压的在制车（含本批 3 台跨停车），周六重启后追产过线流速 ~55 台/h，这批车实际剩余耗时显著短于含常规排队等待的 P50；静态模型用常规 rem（相对现场偏长）→ t+rem > 班次末 → 漏计 → 低估。即：**节前停线未建模 → 单车 rem 偏短、ETA 偏早；节后追产加速 → 静态 rem 相对偏长、班次漏计**。原“同根因两表现”表述修正为“停线前后互补的非稳态扰动”（详见 `scratch/tmp_kw39_replay10_review_findings.md` F-03）。

**停线事实口径正名（agy-2 F-04）**：09-25“39 条残余事件”实为 **3 个入口工位事件 39 条**（00:00~01:00）；全厂事件 2,734 条（其中 2,720 条为 00:00~02:34 的 09-24 中班延时尾部），02:34 后整厂停工、当日 4 个下线点事件为 0。原“当日库里仅 39 条残余过站事件”混淆了入口事件与全厂事件。

**B. 稀有车型前决策补偿失稳（XV32Q- 78202663907042，入口 +3579.6 min）**
入口 ETA = t + 80.2h，构成分解（真库实证）：主分布 28.86h（1L360RB 无 XV32Q- 行，回退 ALL，合理）+ **p×L 补偿 51.4h** = p1×L1 + p2×L2 = 0.615×70.7h + 1.0×7.9h。p/L 取自**车型专属行**（fut n=65、loop_dur(1) n=40——均**通过** min_n=30 门槛，非 ALL 回退），但小样本退化：p2=1.0（ALL 行仅 0.022）、L1 P50=70.7h（ALL 仅 13.6h）。实际旅程仅 20.6h（黑顶环 ~5h、几乎无返工），p1×L1 一项（43.5h）即超实际总耗时。
**机制 = 小样本车型专属 p/L 行通过 n≥30 门槛后的退化，而非“ALL 回退偏长”**；对应已拍板修正方向 = W2⑥ 逐车型补偿质量标 + W4 期望净延迟（p50）替代 p×L 公式。末端覆盖缺失（agy-2 实证）：并非“末 2 站”，而是**末端连续 7 站**（25IS365 → L3ATK11IS02，轨迹表步长 5 采样仅展示 2 站）；SS22H- 进环车 78202682685297 同样**末端连续 8 站**（25IS395 → K3IS055）无 ETA。机理：两车 25IS 出环网关离环后，MDS_DATA 139 位在原始数据中**未复位**（仍 '1'/'2'），W1 旧式路径**无 W4.4c `loop_exited` 出环守卫** → 残留环 flag 遍历下游主线站 → `dim_loop_remaining` 无样本 → 末端连续无覆盖、末站误差 NaN。此即 W4.4c 出环守卫必要性的数据再实锤（F-1/F-2）；W4 统一引擎残留位冻结按主线分类即可覆盖。

**SS22H- 非稀有车型（agy-2 澄清）**：窗内 53,697 条事件、全厂第 5 大主力车型，01IS205 有自身模型行（n=1778，P50=22.73h）；其入口误差（+574/+1022 min）属**跨夜混合 P50 地板**类（日间快车 8.8/16.2h vs 含跨夜等待的 P50），非稀有车型回退。原呈报将其与 XV32Q- 并列为“稀有车型”的表述撤回。
